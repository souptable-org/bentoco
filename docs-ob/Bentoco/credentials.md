# BentoCo Login Credentials & Setup

This document lists the credentials and configuration mappings for local testing of the BentoCo Merchant and Agency dashboards.

## Credentials

| Role | Email | Password | Redirects To |
|---|---|---|---|
| **Merchant** | `admin@bentoco.com` | *Any password* | `/orders` (Merchant Dashboard) |
| **Agency** | `agcy@bentoco.com` | *Any password* | `/agency/dashboard` (Agency Dashboard) |

---

## Server Port Mapping

* **Vite Dashboard Frontend**: [http://localhost:7001](http://localhost:7001)
* **Express API Engine**: [http://localhost:9000](http://localhost:9000)
