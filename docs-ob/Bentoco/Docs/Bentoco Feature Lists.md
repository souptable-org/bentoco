Here is the complete feature list for the MVP, with each feature on a single line:

- 4–5 hardcoded, high-performance Vercel-inspired page structures (Hero, Catalog, Product Detail, Cart, Checkout).
    
- A deterministic backend `DESIGN.md` compiler that instantly maps YAML token variables to CSS root variables for 1-click theme swapping.
    
- Custom Domain Mapping with automated Cloudflare/Vercel SSL provisioning for immediate branding.
    
- Sub-1-Second Static HTML/SSG edge-rendered storefronts optimized for Indian 4G mobile networks.
    
- "Bring Your Own Gateway" (BYOG) native API integrations for Razorpay, Cashfree, and PhonePe.
    
- 1-Click UPI Intent Checkout that opens GPay, PhonePe, or Paytm natively on mobile without browser redirects.
    
- Mandatory WhatsApp/SMS 4-digit OTP verification step prior to Cash-on-Delivery (COD) order confirmation.
    
- Frictionless Guest Checkout requiring only Name, Phone, Address, and Pincode.
    
- Native Shiprocket and Delhivery API integrations for 1-click AWB generation and shipping label printing.
    
- Automated GST-compliant PDF invoice generation with HSN codes and tax breakdown.
    
- WhatsApp automation powered by Evolution API, an open-source middleware that connects to WhatsApp via the Baileys protocol.
    
- QR-code based WhatsApp onboarding via Linked Devices, bypassing Meta's corporate verification and per-message API fees.
    
- Prepaid Communications Wallet allowing merchants to pre-fund automated message costs via UPI.
    
- Automated WhatsApp transactional notifications for Order Confirmations, Dispatch Tracking links, and Out for Delivery alerts.
    
- Automated WhatsApp Abandoned Cart recovery pings triggered 30 minutes after checkout drop-off.
    
- 1-Screen Catalog Manager featuring variant support, stock counters, and automated WebP image compression.
    
- 1-Click Shopify CSV Catalog Importer to instantly port titles, prices, descriptions, and images in seconds.
    
- Minimalist Merchant Admin Dashboard displaying daily gross sales, pending COD approvals, dispatched items, and return requests.
    
- Server-Side Meta (FB/IG) Conversion API and Pixel integration to track events while bypassing iOS 14+ ad blockers.
    
- Promo and Discount Engine supporting percentage-off, flat-rate, and free-shipping codes with minimum order thresholds.
    
- Pre-built "Vibe Presets" (Cyber-Brutalist, Warm Minimalist, Editorial Luxury) applied instantly without editing code.

apps we need as Features 
- **Pincode Serviceability Checker:** A native widget on product pages that validates delivery times and COD availability using the Shiprocket/Delhivery API before the user reaches checkout.
    
- **Smart Address Auto-Complete:** An checkout script that automatically fills in the City and State the moment a buyer types their 6-digit Indian pincode, reducing dropped deliveries.
    
- **WhatsApp Photo Reviews:** An automated post-delivery WhatsApp ping that asks the buyer for a photo and a rating, automatically pushing 5-star reviews to the product page (replacing apps like Loox or Judge.me).
    
- **Floating WhatsApp Support Widget:** A lightweight, native chat button that opens directly to the merchant's WhatsApp Business number (replacing bloated chat apps like Tidio or Intercom).
    
- **Post-Purchase Upsell Engine:** A native modal that offers a complementary product immediately after checkout, adding it to the existing order with one click (replacing Zipify or CartHook).
    
- **In-Cart Order Bumps:** A simple checkbox in the slide-out cart offering low-ticket add-ons (like priority shipping or extended warranty) to increase Average Order Value.
    
- **Native RTO & Returns Portal:** A self-serve tracking and exchange page where buyers can request a return and upload images of damaged goods without messaging the founder (replacing EcoReturns).
    
- **Dynamic Size Charts:** Configurable size guide modals that can be universally linked to specific apparel categories, reducing return rates on clothing.
    
- **Sticky "Add to Cart" Mobile Bar:** A high-converting buy button that stays pinned to the bottom of the screen as the user scrolls through long product descriptions on mobile.
    
- **Auto-Syncing Meta/Google Catalogs:** A native XML feed generator that automatically keeps Facebook Shops and Google Merchant Center updated with real-time stock and pricing (replacing Flexify).
    
- **Micro-Affiliate Link Generator:** A simple dashboard tab where merchants can create trackable discount links for Instagram influencers and view their exact sales conversions (replacing GoAffPro).
    
- **Real-Time Scarcity Badges:** Authentic, inventory-linked UI tags (e.g., "Only 2 left in stock") that display automatically when stock levels drop, avoiding the spammy feel of fake countdown timers.
